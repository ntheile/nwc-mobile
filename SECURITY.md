# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ntheile/nwc-mobile/security/advisories/new).
Do not open a public issue until the report has been investigated and a fix is
available.

Include, when possible:

- the affected revision or release;
- the violated security property;
- reproduction steps or a proof of concept;
- the expected impact; and
- any suggested remediation.

Do not include production wallet seeds, Nostr secrets, NWC connection URIs,
push tokens, invoices, or personally identifying payment data in a report.

## Supported versions

The project is pre-release. Until the first published release, security fixes
are made on the `main` branch and no compatibility support window is promised.
